# Las páginas de Dani ⚡

> Sitio web oficial de **Las páginas de Dani**: Diseño de páginas web profesionales en 24 horas con tarjeta inteligente NFC en Colombia.

## 🚀 Características del Proyecto
- **Diseño Original y Profesional:** Paleta de colores corporativa `#0A192F` con acentos en naranja `#FF7A00` y verde `#00C853`.
- **Arquitectura Modular (Separación de Incumbencias):**
  - Estructura: HTML5 semántico accesible.
  - Estilos: `css/main.css`, `css/components.css`, `css/animations.css`.
  - Lógica: `js/navigation.js`, `js/animations.js`, `js/pricing.js`, `js/whatsapp-modal.js`, `js/lazy-media.js`, `js/app.js`.
- **Animaciones Integradas:** Efectos de scroll reveal diferidos, hover con microinteracciones y entrada/salida de modales.
- **Optimización de Carga:** Lazy loading nativo + IntersectionObserver para animaciones e imágenes.
- **SEO & OpenGraph:** Metadatos estructurados, JSON-LD Schema.org y etiquetas Open Graph.
- **Auto-Deploy:** Despliegue automatizado con GitHub Actions hacia Surge.sh (`las-paginas-de-dani.surge.sh`).
